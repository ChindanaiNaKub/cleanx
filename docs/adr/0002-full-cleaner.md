# Clean reported large and hidden items

cleanX used to report hidden and large files without offering to clean them. We now make them Caution Candidates the user may select, while a short protected-folder list is reported but never offered. This trades the guarantee that the app only deletes a fixed allow-list for real space recovery. Two-press confirmation, Caution items off by default, and an explicit HANDS OFF tag keep that trade visible.
